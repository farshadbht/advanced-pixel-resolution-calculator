# Advanced Pixel Resolution Calculator

A lightweight, offline Windows desktop utility for calculating image pixel counts and converting resolutions between aspect ratios.

## Planned features

- Popular aspect-ratio presets, including landscape, portrait, square, and ultrawide formats
- Popular resolution presets that update when the selected aspect ratio changes
- Custom aspect-ratio input
- Custom width and height input
- Automatic total-pixel and megapixel calculation
- Convert a pixel count to the closest integer resolution for another aspect ratio
- Optional even-dimension rounding for image-processing compatibility
- Copy calculated resolutions to the clipboard

## Technology

The application is planned in Python with Tkinter for a lightweight desktop interface. The goal is to run offline and require no third-party packages for the core calculator.
